## [2.5.0] - 2025-09-28
### Added
- OpenAPI 3.1.0 machine-readable spec endpoint at `/api/openapi`
- Multi-modular `@vaulthost/sdk` with 6 domain modules
- Idempotency engine with SHA-256 collision detection
- Interactive API Reference Explorer at `/docs/api`
- Action Gateway Visualizer embedded in admin panel
- S3CodePlayground multi-language interactive component
- DNSApiPlayground interactive console
